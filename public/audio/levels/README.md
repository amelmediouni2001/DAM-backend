## Batman Theme
**File:** `batman-preview.mp3`
**Source:** Use royalty-free Batman-style orchestral theme
**Recommended:** 
- YouTube Audio Library: "Dark Hero" or "Epic Cinematic"
- FreeMusicArchive.org: Search "cinematic dark orchestral"
- Incompetech.com: "Darkest Child" by Kevin MacLeod

**Format:** MP3, 128kbps or higher
**Duration:** 10-15 seconds (intro snippet)
**Mood:** Dark, mysterious, heroic

## How to Add
1. Download royalty-free music
2. Trim to 10-15 seconds using Audacity or online tool
3. Export as MP3
4. Save as `batman-preview.mp3` in this directory
5. Update level document with URL: `http://YOUR_IP:3000/audio/levels/batman-preview.mp3`
